

# 🎬 字幕批量调轴工具 (Subtitle Sync Tool)

## 📖 软件介绍

这是一个基于 Windows 11 原生 PowerShell 环境开发的轻量级字幕批量调轴脚本。
不需要安装 Python，也不需要下载任何第三方字幕编辑软件。只需一次点击，即可通过可视化的文件选择框，批量对多种主流格式的字幕文件进行时间轴的正负偏移调整。

### ✨ 核心特性
* **🟢 原生纯净**：纯 PowerShell 脚本（`.ps1`），依赖 Windows 原生组件，无需安装任何额外环境。
* **📁 格式通吃**：智能识别并完美支持 `.srt`、`.vtt`、`.ass`、`.ssa` 四大主流字幕格式，支持不同格式混合批量处理。
* **🛡️ 安全无损**：在执行任何覆盖修改前，会自动在字幕原目录创建 `backup` 文件夹并备份原始文件，绝不丢失原数据。
* **📺 播放器兼容**：处理后的字幕统一采用**无 BOM 的 UTF-8** 编码保存，完美兼容 PotPlayer、VLC 等主流播放器，杜绝画面顶部出现乱码字符。

## 🚀 使用步骤

### 第一步：创建脚本文件
1. 在电脑任意位置（例如桌面）新建一个文本文档。
2. 将提供的 PowerShell 代码完整粘贴进去。
3. 点击记事本左上角的 **“文件” -> “另存为...”**。
4. **【关键】** 在底部的“编码”下拉菜单中，**必须选择“带有 BOM 的 UTF-8”或“ANSI”**。
5. 将文件命名为 `字幕批量调轴.ps1`，点击保存（请确保文件后缀是 `.ps1`，而不是 `.ps1.txt`）。

### 第二步：运行调轴
1. 找到你刚刚创建的 `字幕批量调轴.ps1` 文件。
2. **不要双击**，请**右键点击该文件**，在菜单中选择 **“使用 PowerShell 运行”**。
3. 在弹出的窗口中，按住 `Ctrl` 或 `Shift` 键批量选择你需要调轴的字幕文件，点击确定。
4. 在黑色命令行窗口中输入时间偏移量：
    * **正数**：字幕延后（例如输入 `500` 表示延后 0.5 秒）
    * **负数**：字幕提前（例如输入 `-1500` 表示提前 1.5 秒）
5. 按下回车，脚本将在几秒内完成自动备份和调轴。

## ❓ 常见问题解答 (Q&A)

### Q1：右键选择“使用 PowerShell 运行”后，窗口闪现一下就直接消失了（闪退）？
**答：** 这通常是因为 Windows 11 默认的安全策略禁止运行未签名的本地脚本。
**解决方法：**
1. 右键点击 Windows 开始菜单图标，选择 **“终端 (管理员)”** 或 **“Windows PowerShell (管理员)”**。
2. 输入命令 `Set-ExecutionPolicy RemoteSigned` 并按回车。
3. 系统提示时输入 `Y` 并按回车确认。
4. 关闭窗口，再次右键运行脚本即可。

### Q2：运行脚本后，命令行里出现大片红字报错，还包含像“璇锋寜”这样的乱码？
**答：** 典型的文件编码冲突问题。Windows 11 记事本默认使用纯 UTF-8 编码，而 PowerShell 读取时按 ANSI 解码，导致代码里的中文字符变成乱码并破坏了脚本结构。
**解决方法：**
右键脚本文件选择“在记事本中编辑”，点击“文件” -> “另存为”，在底部的编码选项中将“UTF-8”改为 **“带有 BOM 的 UTF-8”**，然后覆盖保存即可。

### Q3：如果我把时间轴调错了，还能恢复吗？
**答：** 绝对可以。脚本在处理每个字幕文件前，都会在当前文件夹下自动创建一个 `backup` 文件夹，并将未经任何修改的原始文件原封不动地复制进去。如果调错了，直接从 `backup` 文件夹把原文件拿出来覆盖回去即可。

### Q4：时间偏移量怎么计算？
**答：** 脚本使用的是**毫秒**作为单位（1 秒 = 1000 毫秒）。
* 如果你觉得声音出来了，但字幕过了 2 秒才出来（字幕慢了，需要提前），请输入 `-2000`。
* 如果你觉得字幕出来了，但过了 1.5 秒声音才出来（字幕快了，需要延后），请输入 `1500`。

### Q5：我可以同时选择 SRT 和 ASS 格式的文件一起处理吗？
**答：** 可以。脚本内置了自适应时间轴处理逻辑，你可以随意混合框选支持的格式，程序会自动判断每个文件的后缀名，并套用对应的时间轴解析正则去处理，互不干扰。
